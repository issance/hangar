---
title: Install Hangar
description: Install, update, and verify Hangar on Linux and macOS.
---

Hangar ships as a single binary for Linux and macOS.

## Install

Run the installer:

```bash
curl -fsSL https://issance.com/install.sh | sh
```

The installer downloads the right release binary for your platform and places it on your PATH.

## Verify

Start Hangar:

```bash
herdr
```

If your shell cannot find `hangar`, restart the terminal or check that the install directory is on your PATH.

## Update

Hangar checks for new releases and notifies you in the app. You can update manually:

```bash
hangar update
```

## Download manually

You can also download a binary from [GitHub releases](https://github.com/issance/hangar/releases).

Choose the asset that matches your system:

| System | Asset |
| --- | --- |
| Linux x86_64 | `herdr-linux-x86_64` |
| Linux aarch64 | `herdr-linux-aarch64` |
| macOS Intel | `herdr-macos-x86_64` |
| macOS Apple silicon | `herdr-macos-aarch64` |

Make it executable and move it somewhere on your PATH.

```bash
chmod +x herdr-linux-x86_64
mv herdr-linux-x86_64 ~/.local/bin/herdr
```

## Requirements

Hangar supports Linux and macOS. Native Windows support is not available yet; use Hangar inside WSL for now.
